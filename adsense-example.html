Step 2: Alternative Manual Implementation

If you prefer to paste AdSense code directly into HTML files instead of using the JavaScript configuration, here's how:

Example: Manual AdSense Code

Replace the ad container divs with actual AdSense code from your AdSense account:

<!-- Replace this: -->
<div id="adsense-header-banner" class="adsense-container"></div>

<!-- With this (example AdSense code from your account): -->
<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-6832553346534070"
     crossorigin="anonymous"></script>
<ins class="adsbygoogle"
     style="display:block"
     data-ad-client="ca-pub-6832553346534070"
     data-ad-slot="YYYYYYYYYY"
     data-ad-format="auto"
     data-full-width-responsive="true"></ins>
<script>
     (adsbygoogle = window.adsbygoogle || []).push({});
</script>
ℹ️ Note: If using manual implementation, you can remove the adsense-config.js script reference from your HTML files.

Step 3: Getting Your AdSense Code

  1. Sign in to your Google AdSense account
  2. Go to Ads → By ad unit
  3. Click "+ New ad unit" or select an existing one
  4. Choose ad type (Display ads recommended)
  5. Configure ad size and settings
  6. Click "Create" and copy the generated code
  7. Paste the code values into adsense-config.js

Finding Your Publisher ID:

  • In AdSense, go to Account → Settings
  • Your Publisher ID is listed (format: ca-pub-6832553346534070)

Finding Ad Unit IDs:

  • In AdSense, go to Ads → By ad unit
  • Click on an ad unit to see its ID (10-digit number)
  • Or copy from the ad code snippet (data-ad-slot value)

Step 4: Test Your Implementation

⚠️ Testing Notes:
  • Ads may not show on localhost - test on a live domain
  • Disable ad blockers during testing
  • It may take a few hours for new ad units to start serving
  • Never click your own ads (policy violation)

Verification Checklist:

  • ✅ AdSense account is approved and active
  • ✅ Publisher ID is correctly set in adsense-config.js
  • ✅ All ad unit IDs are correctly set
  • ✅ adsense-styles.css is linked in HTML
  • ✅ adsense-config.js is loaded before closing body tag
  • ✅ Ad containers exist in HTML with correct IDs
  • ✅ Site is deployed to a live domain (not localhost)
  • ✅ No JavaScript errors in browser console
