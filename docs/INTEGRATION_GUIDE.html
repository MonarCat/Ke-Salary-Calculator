🇰🇪 Integration Guide

Step-by-step instructions for wiring all premium and monetisation components into the Kenya Salary Calculator.

Step 1 — Run the SQL Migration

Open the Supabase SQL Editor and run the contents of:

database/004_premium_and_newsletter.sql

This adds premium, premium_expires_at, premium_source columns to user_profiles, creates the paypal_transactions audit table, updates newsletter_subscribers, and creates the check_premium_active() and grant_premium() SQL functions.

⚠️ Order matters. Run this after blog-schema-additions.sql because it requires the user_profiles table to already exist.

Step 2 — Deploy the Vercel Webhook Function

2a. vercel.json

Ensure this file exists at the repository root (already included in this project):

{
  "functions": {
    "api/**/*.mjs": { "runtime": "nodejs20.x" }
  }
}

2b. Environment variables (Vercel dashboard)

Go to Project settings → Environment Variables and add:

VariableValue
SUPABASE_URLYour Supabase project URL, e.g. https://xyzxyz.supabase.co
SUPABASE_SERVICE_KEYYour Supabase service-role key (keep secret!)
PAYPAL_MODElive or sandbox

2c. PayPal IPN URL

In your PayPal account go to Account Settings → Instant Payment Notifications and set the notification URL to:

https://<your-vercel-site>.vercel.app/api/paypal-webhook

Or update the notify_url field in your PayPal button form:

<input type="hidden" name="notify_url"
       value="https://<your-vercel-site>.vercel.app/api/paypal-webhook" />

Step 3 — Update calculator.html

3a. CSS links (inside <head>)

These are auto-injected by calculator-enhancements.js, so no manual <link> tags are needed. Skip to 3b.

3b. Add placeholder <div> elements

Place these divs in the appropriate locations inside the results section of calculator.html:

<!-- Share result – place immediately after the results table -->
<div id="ke-share-result" style="display:none;"></div>

<!-- Financial tools – place after the share bar -->
<div id="ke-financial-tools" style="display:none;"></div>

<!-- Newsletter – place near the bottom of the main content area -->
<div data-ke-newsletter="calculator"></div>

<!-- Ad slots – place where you want ads to appear -->
<div id="ke-ad-top"></div>
<div id="ke-ad-mid"></div>
<div id="ke-ad-bottom"></div>

3c. Load the entry-point script

Add this after the existing <script> tags at the bottom of calculator.html:

<!-- Premium & monetisation components -->
<script src="src/components/calculator-enhancements.js" defer></script>

3d. Dispatch event from calculateSalary()

Open assets/js/script.js and find the end of the calculateSalary() function (just before the closing } of the function, after the call to generateShareLink()).

Add this one line:

    // Notify premium/share/financial-tools components
    window.dispatchEvent(new CustomEvent('salaryCalculated', { detail: {
        grossPay, netPay, paye, nssf, shif, housingLevy, totalIncome
    }}));

Step 4 — Update PayPal Premium Button

Open src/components/premium.js and replace PREMIUM_BUTTON_ID with your actual PayPal subscription button ID:

<input type="hidden" name="hosted_button_id" value="YOUR_ACTUAL_BUTTON_ID" />

Step 5 — index.html (optional newsletter)

To show the newsletter block on the homepage, add:

<!-- Newsletter block -->
<div data-ke-newsletter="index"></div>

<!-- Load newsletter component -->
<script src="src/components/newsletter.js" defer></script>
<link rel="stylesheet" href="src/components/newsletter.css">

Step 6 — Manually Activate M-Pesa Payments

For users who pay via M-Pesa, call grant_premium() directly from the Supabase SQL Editor:

SELECT grant_premium(
    'user-uuid-here',   -- p_user_id
    'mpesa',            -- p_source
    30                  -- p_duration_days
);
